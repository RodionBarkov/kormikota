# 🐯 КормиКота

Домашний учёт продуктов и бытовой химии, список покупок и журнал кормлений Тигры.
Каждое действие подписывается: кто и когда.

## Что внутри

| Вкладка | Что делает |
|---|---|
| 🛒 **Купить** | Всё, что «мало» или «нет». В магазине нажимаете на строку — товар куплен (зачёркнут, дома снова «есть»). Нажали по ошибке — нажмите ещё раз. Нажмите на фото, чтобы увидеть его крупно: так понятно, какой именно товар брать. Сверху поле «Что купить?»: начните вводить, и оно подскажет из того, что уже есть в учёте. |
| 🏠 **Дома** | Всё, что есть, по категориям. Справа у каждой позиции три кнопки: **Есть / Мало / Нет**, хватает одного нажатия. Нажмите на название, чтобы добавить фото, заметку или сменить категорию. Там же видна история позиции. **＋** внизу добавляет новую позицию. |
| 🐯 **Тигра** | Большая кнопка «Тигра покормлена». Видно, сколько прошло времени с последнего кормления и кто кормил. Забыли отметить сразу? Нажмите **«Указать время»** и выберите «1 ч назад» или точные день и время. Ниже история по дням: сколько раз и чем кормили. Дни без кормлений отмечены «не отмечали». Нажмите на запись, чтобы исправить время или корм. Можно поставить фото Тигры. |
| 🕓 **История** | Все действия всех людей: кто, что и во сколько. Есть фильтр по человеку. |
| ⚙️ **Ещё** | Своё имя, цвет и пароль, категории, установка на телефон. Админу доступно управление пользователями. |

Если у позиции нет фото, вместо него показывается эмодзи по названию (молоко 🥛, порошок 🧺, корм 🐱 и т. д.).
Фото сжимаются прямо на телефоне до ~50–150 КБ, поэтому места на сервере и трафика уходит мало.

## Запуск на компьютере

Дважды щёлкните **`start.bat`**: откроется браузер с КормиКота.

- При первом запуске создаётся суперадмин. Логин `admin`, пароль показан в чёрном окне и сохранён в `data\ADMIN_PASSWORD.txt`. Когда смените пароль, файл удалится сам.
- С телефона в той же Wi-Fi сети откройте адрес вида `http://192.168.x.x:8000` (он показан в окне). Если Windows спросит про брандмауэр, разрешите доступ.
- Все данные лежат в папке `data` (база `kormikota.db` и фото). Для резервной копии достаточно скопировать эту папку.

## Заливка на PythonAnywhere (бесплатно)

Выбран PythonAnywhere: у него на бесплатном тарифе **постоянный диск**, так что база и фото не пропадают.
На Render, Koyeb и подобных бесплатный диск стирается при каждом перезапуске, и все данные будут теряться.

1. Зарегистрируйтесь на <https://www.pythonanywhere.com> (тариф **Beginner — Free**).
   Логин станет адресом сайта: `https://ЛОГИН.pythonanywhere.com`.
2. На компьютере запустите **`make_zip_for_hosting.bat`**: рядом появится `kormikota.zip`.
3. На сайте откройте **Files** → **Upload a file** и загрузите `kormikota.zip`.
4. Откройте **Consoles** → **Bash** и выполните:
   ```
   unzip -o kormikota.zip -d kormikota
   ```
5. Откройте **Web** → **Add a new web app** → Next → **Manual configuration** → Python **3.10 или новее** → Next.
6. На странице **Web** нажмите ссылку **WSGI configuration file**, удалите всё содержимое и вставьте текст из `pythonanywhere_wsgi.py`.
   Вместо `ВАШ_ЛОГИН` подставьте свой логин. Нажмите **Save**.
7. На странице **Web** включите **Force HTTPS** и нажмите зелёную кнопку **Reload**.
8. Откройте `https://ЛОГИН.pythonanywhere.com`. Пароль админа: **Files** → `kormikota/data/ADMIN_PASSWORD.txt`.
9. Войдите, смените пароль (**Ещё → Пароль**) и создайте пользователей (**Ещё → Пользователи → Добавить человека**).

**Обновление кода:** повторите шаги 2–4 (папка `data` с базой и фото не затрагивается), затем **Web → Reload**.

**Важно:** на бесплатном тарифе PythonAnywhere периодически присылает письмо с просьбой продлить сайт.
Нужно зайти на вкладку **Web** и нажать **Run until … from today**. Если не нажать, сайт выключится, но данные останутся.

**Резервная копия:** в Bash-консоли выполните `zip -r backup.zip kormikota/data`, затем скачайте `backup.zip` во вкладке Files.

## Установка на телефон (как обычное приложение)

**iPhone:** откройте сайт в **Safari** → кнопка **Поделиться ⬆︎** → **На экран «Домой»** → **Добавить**.

**Android:** откройте сайт в **Chrome**. Есть два способа:
- во вкладке **Ещё** нажмите кнопку **«📲 Установить приложение»** (она появляется сама);
- или в меню **⋮** выберите **Установить приложение** / **Добавить на главный экран**.

На обоих телефонах появится иконка с тигром. Приложение откроется на весь экран без адресной строки, а вход запоминается на год.
Список покупок и фото открываются даже в магазине без связи (последнее загруженное состояние). Отметки при этом требуют интернета.

> Установка на Android работает только через **https** (то есть после заливки на хостинг).
> При локальном запуске по `http://192.168…` сайт открывается, но кнопки «Установить» не будет.

## Файлы

```
app.py                     — сервер (только стандартная библиотека Python, ничего ставить не нужно)
static/                    — интерфейс: index.html, app.js, style.css, иконки, манифест, сервис-воркер
data/                      — база и фото (создаётся сама, в архив для хостинга не попадает)
start.bat                  — локальный запуск
make_zip_for_hosting.bat   — собрать архив для заливки
pythonanywhere_wsgi.py     — что вставить в WSGI-файл на PythonAnywhere
```
